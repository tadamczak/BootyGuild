# BootyGuild

BootyGuild provides a persistent guild roster, member details and guild statistics with the shared Booty interface.

Install `BootyGuild` and its required `BootyLib` folder in `Interface/AddOns`, then restart the game. Without Booty Suite, use the BootyGuild minimap icon to open Guild, Guild Stats or Settings. Installing Booty Suite combines these views and settings into the Suite window automatically.

Join a guild to use Guild and Guild Stats. Scan Guild Data to capture the roster. Live tracking refreshes guild data only while the Guild page is visible. Guild Stats supports sorting, filters and grouped or raw results. Export Guild captures fresh data and offers a reload to save it to disk.

Standalone Settings has two main sections: **Profile** and **Guild**. Use **Profile → General** to add, save, load, delete or export named settings profiles in either standalone mode or Booty Suite. Reset restores settings defaults and retains guild data.
